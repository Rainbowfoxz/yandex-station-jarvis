# Джарвис на Яндекс Станции 2

Мод для рутованной Яндекс Станции 2 (в device-tree — «Yandex Station Midi»): колонка отзывается на «Джарвис»,
вопрос уходит в Gemini, ответ звучит клонированным голосом Джарвиса из русского дубляжа. Алиса, аккаунт Яндекса
и Яндекс Музыка продолжают работать как раньше: команды вроде «включи музыку» Джарвис передаёт Алисе.

Проверено на одной колонке (прошивка октября 2026) и одном ПК с Windows 11. Это рабочие скрипты, а не готовый
установщик: шаги ниже повторяют то, как было сделано, и наверняка потребуют правок под другую колонку.

## Как это устроено

```
 Колонка (root, SSH :2222)                     ПК с Windows
 ┌───────────────────────────┐   SSH   ┌──────────────────────────────────────┐
 │ микрофоны ─ asound.conf ──┼────────►│ jarvis_wake.py                       │
 │   (копия входа Алисы)     │ pull.sh │  ├ aec.py: вычесть звук динамика     │
 │                           │         │  ├ Vosk: «Джарвис» + вопрос          │
 │ Алиса :9875 ◄─────────────┼─────────┤  ├ gemini_brain.py: вопрос ЗВУКОМ    │
 │   (команды, текст)        │ туннель │  │    -> ответ или «АЛИСА: команда»  │
 │                           │         │  └ jarvis_tts_server.py (F5-TTS) ──┐ │
 │ maind --gst-launch ◄──────┼─────────┤     голос Джарвиса, PCM потоком ◄──┘ │
 │ подсветка /dev/fb0        │         │                                      │
 └───────────────────────────┘         └──────────────────────────────────────┘
```

- **Микрофон.** Микрофоны монопольно держит platformd, dsnoop на этой модели вешает Алису. Работает плагин ALSA
  `file`: копия того, что читает Алиса (6 каналов, 48 кГц), идёт в `mic/sink.sh`, оттуда по SSH (`mic/pull.sh`)
  на ПК. Каналы 4–5 — опора динамика, по ней `aec.py` вычитает музыку и голос Алисы, иначе под музыкой
  «Джарвис» не слышно.
- **Распознавание.** Vosk (small ru) ловит «Джарвис». Сам вопрос Gemini получает звуком: на живом голосе Vosk
  и Whisper путали слова. Под музыкой на «Джарвис» Алиса сама приглушает музыку и распознаёт вопрос,
  слушатель перехватывает её текст.
- **Алиса.** Порт 9875 на колонке (протокол из quasar-protos): текстовый вопрос (`ask_text.py`), озвучка текста
  её голосом (`say.py`), события распознавания (`alice_watch.py`).
- **Ответ.** `gemini_brain.py` — характер дворецкого, память разговора на 5 минут, перебор моделей при
  перегрузке Google. Если все модели легли, Джарвис говорит об этом и передаёт вопрос Алисе.
- **Голос.** F5-TTS с русской моделью ESpeech-TTS-1_SFT-256K, дообученной на репликах Джарвиса
  (`jarvis_voice.py`, `jarvis_tts_server.py`). Ответ синтезируется по предложениям и играет потоком через
  `maind --gst-launch`, первое предложение звучит, пока дописываются остальные.
- **Подсветка.** Анимации Алисы перекрашены в золото (`led/gold.py`), «думаю» и «говорю» — свои кадры в
  `/dev/fb0` (`led/make_frames.py`, `led/anim.sh`).

## Что нужно

- Яндекс Станция 2 с root. Рут получали способом с DNS из вики hackalice (страница station-2.md) на прошивке
  0.369.1.46 и сразу отключили обновления; на более новых прошивках не проверяли. Ядро 64-битное, система
  32-битная armhf, Python на колонке нет.
- SSH на колонке: dropbear на порту 2222, автозапуск — `S99zdropbear` в `/etc/init.d`. Бинарники dropbear в
  архив не входят — соберите под armhf или возьмите из проверенного источника, положите в `/data/opt/bin`.
  **Внимание:** скрипт запускает dropbear с пустым паролем root (`-B`) — в общей сети замените на вход по ключу.
- ПК с Windows, Python 3.11+ (`py`), OpenSSH-клиент, ffmpeg в PATH.
- Для голоса — видеокарта NVIDIA (проверено на RTX 5070, 12 ГБ) и отдельное окружение под F5-TTS.
- Ключ Gemini API (aistudio.google.com) — бесплатного уровня хватает.

## Настройка

Настройки берутся из переменных окружения, а если их нет — из файла `jarvis.local.json` рядом со скриптами:

```json
{"JARVIS_HOST": "192.168.1.50", "JARVIS_SSH_PORT": "2222", "GEMINI_ENV_FILE": "C:/keys/.env"}
```

| Настройка | Что это | По умолчанию |
|---|---|---|
| `JARVIS_HOST` | IP колонки в домашней сети (в приложении «Дом с Алисой» или в роутере) | `192.168.1.100` |
| `JARVIS_SSH_PORT` | порт dropbear на колонке | `2222` |
| `GEMINI_ENV_FILE` | файл, где есть строка `GEMINI_API_KEY=ваш_ключ` | `.env` рядом со скриптами |
| `GEMINI_API_KEY` | сам ключ — можно задать переменной вместо файла | — |

`jarvis.local.json` и `.env` в репозиторий не коммитьте.

Пути к моделям считаются от домашней папки: `~/Downloads/vosk/vosk-model-small-ru-0.22`,
`~/Downloads/f5-tts` (окружение, модели, данные), `~/Downloads/whisper`.

## Установка

### Колонка

1. Отключить обновления: `sh yandex-noupdate.sh` (оригиналы сохраняются в `/data/opt/backup`, откат — `restore`).
   Иначе OTA может откатить мод и закрыть рут.
2. Микрофон. Скопировать с колонки `/etc/asound.conf` в `mic/asound.conf.orig`, собрать `py mic/make_asound.py`,
   получившийся `mic/asound.conf` положить в `/etc/asound.conf` (корень монтировать `mount -o remount,rw /`).
   `mic/sink.sh` и `mic/pull.sh` — в `/data/opt/jarvis/`.
3. Подсветка. Штатные анимации лежат в `/system/vendor/quasar/ledpatterns/{panel,oknix}/` — скопировать в
   `led/orig/`, `py led/gold.py` перекрашивает в `led/gold/`. Кадры «думаю/говорю»: `py led/make_frames.py ...`,
   затем `anim.sh`, `think.sh`, `thinking.bin`, `speaking.bin` — в `/data/opt/think/`.
4. Короткие реплики Джарвиса (из архива с голосом) — в `/data/opt/jarvis/og/`.
5. По желанию — приватность: `privacy/make_privacy.py` собирает конфиги без телеметрии из копий в `privacy/backup/`.

### ПК

```
py -m pip install vosk numpy scipy soundfile google-genai faster-whisper
```

Окружение для голоса (отдельно, в `~/Downloads/f5-tts/venv`): `f5-tts`, `torch` с CUDA, `ruaccent`,
`soundfile`, `huggingface_hub`; для дообучения ещё `bitsandbytes`, `speechbrain`, `demucs`, `num2words`.

Модель ESpeech скачивается с Hugging Face при первом запуске. Дообученная модель и образцы голоса — архив
`yandex-station-jarvis-voice.zip` в релизе [voice-v1](../../releases/tag/voice-v1) (0,68 ГБ, в git не помещается),
распаковать в `~/Downloads`:

```
gh release download voice-v1 -R Rainbowfoxz/yandex-station-jarvis
```

## Запуск

Два процесса:

```
%USERPROFILE%\Downloads\f5-tts\venv\Scripts\python.exe jarvis_tts_server.py   # голос, 127.0.0.1:19890
py -u jarvis_wake.py                                                           # слушатель
```

Без сервера голоса ответы читает Алиса своим голосом.

Проверки без голоса: вопрос текстом — записать его в `%TEMP%\jarvis_ask.txt` (с `!` в начале — сразу Алисе,
мимо Gemini); фраза голосом Джарвиса — `jarvis_voice.py "Текст"`, проиграть на колонке — `py jarvis.py --file x.wav`.

## Дообучение голоса

`film_jarvis.py` ищет реплики в дорожке фильма → `dataset_review.py` и `dataset_clean.py` (Demucs) готовят
страницы для отбора на слух → `dataset_build.py review|export` собирает датасет → `jarvis_finetune.py`
(обёртка над `f5_tts.train.finetune_cli` с поправками под Windows) → `jarvis_compare.py` сравнивает точки по
похожести и разборчивости. 3,5 минуты реплик и ~30 минут на RTX 5070 подняли похожесть с 0,69 до 0,74–0,77.
Звук фильмов в репозиторий не входит — нужны свои записи.

## Хук для Claude Code

`claude_done.py` — хук Stop: когда Claude Code заканчивает работу, колонка говорит «Запрос выполнен, сэр».
Молчит, пока у сессии работают фоновые агенты. Подключение в `~/.claude/settings.json`:

```json
{"hooks": {"Stop": [{"hooks": [{"type": "command", "async": true, "timeout": 30,
  "command": "py \"C:/путь/к/claude_done.py\" >/dev/null 2>&1 || true"}]}]}}
```

## Остальные скрипты

Отладка и исследование: `alice_probe.py`, `alice_watch.py`, `audio_probe.py` — протокол Алисы и порты колонки;
`mic_*.py`, `mic/dsnoop_test.sh`, `mic/tap_test.*` — микрофон; `stream_latency.py` — задержка потока;
`test_*.py` — эхоподавление, декодер, путь вопроса (часть тестов ждёт записей `*.raw`, их в архиве нет).
`jarvis_listen.py` — ранний вариант: отклик на «Алиса, Джарвис…».

## Известные проблемы — помощь приветствуется

- Только Windows: пути, `py`, команды PowerShell. Перенос на Linux/macOS не пробовали.
- Задержка ответа ~2–3 с; первый звук ждёт и Gemini, и синтез первого предложения.
- В дообученном голосе бывает треск (сбои вокодера) — `declick()` в `jarvis_voice.py` глушит большую часть.
- Gemini на бесплатном ключе временами перегружен (503/504/429) — тогда ответ уходит Алисе.
- Соединение с Алисой, простоявшее часы, однажды молча перестало принимать вопросы; сейчас после минуты
  простоя открывается новое — причину не доказали.
- `pull.sh` раньше копился после обрывов SSH и забивал колонку — проверка: `ps | grep jarvis/pull.sh` (одна копия).
- Протестировано на одной колонке — на других прошивках номера каналов и пути могут отличаться.
